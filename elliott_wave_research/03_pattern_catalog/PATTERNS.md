# パターン辞典

## 推進波 5 波（基本形）

```
        5
       /
      4
     / \
    3   
   /
  2
 / \
1
```

- 1, 3, 5 波 = トレンド方向（推進）
- 2, 4 波 = 逆方向（調整）

## 調整波 3 波動（基本形）

```
 a   c
 /\ /
   b
```

- a = 推進方向 5 波（または 3 波）
- b = 調整 3 波
- c = 必ず推進 5 波

## 調整 3 波動のサブパターン

### 1. ジグザグコレクション
- 比率: a = 5波, b = 3波, c = 5波
- 戻し: b は a に対して 61.8 % 以下
- 長さ: a : c ≈ 1 : 1

### 2. フラットコレクション
- 比率: a = 3波, b = 3波, c = 5波
- 戻し: b は 61.8 % を超え a 波始点付近まで戻る
- 長さ: c が a より長くなりやすい

### 3. イレギュラーフラット
- b 波が a 波の始点を超えてさらに伸びる

### 4. ランニングフラット
- b が a を超える
- c が a の始点まで届かない
- 結果として「調整波なのに全体としてトレンド方向に進む」

## 調整 5 波動（チャートパターンで認識）

| パターン | 特徴 | コメント |
| --- | --- | --- |
| **ペナント** | 上下に三角収束 | いわゆる三角持ち合い |
| **ボックス** | 3 つの山と谷をつける | 典型レンジ |
| **フラッグ** | チャネルラインに平行収束、ブレイクで抜ける | 推進 4 波で出やすく、著者の一押し |

## 推進波のイレギュラー 4 種

### エクステンション
- 1 / 3 / 5 波のどれかが大幅延長
- 延長した波内部で同じ時間足の 5 波動が明確に観察できる
- リアルタイム認識は難しく、後追いで気づくことが多い

### ランニングコレクション
- 2 波が戻らずほぼ即 3 波突入
- 急騰・急落でカウントが合わないときはこれを疑う

### フェイラー
- 5 波が 3 波を超えずに反転
- 勢いがない／1 波が異常に長いときに起きやすい

### エンディングダイアゴナル
- 5 波の中身がさらに 5 波動
- 1 波と 4 波が重なるルール破りが許容される（唯一の例外）
- 勢いの弱い終末局面で出る
