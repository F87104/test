# バックテスト仕様メモ（草稿）

このリポジトリには既に H1 ベースの CSV データ（AUDJPY / CHFJPY / EURJPY / GBPJPY / USDJPY / NAS100 / SPX500 / XAUUSD / SILVER の 2014–2026）と、`forex_tester_sai_scanner/` / `pine/` / `backtests/` のディレクトリがある。これらを使って 5 波狙い手法をバックテスト化するための仕様メモ。

## 1. 入力データ

- 中期足相当: `*_H1_YYYY.csv`（既存）
- 短期足: 必要なら H1 から M15 を別途取得、もしくは USDJPY M5 を実験用に利用
- 長期足: H1 を時間集約して D1 / H4 を生成

## 2. シグナル生成アルゴリズム（初版）

```
入力: 中期足 OHLC, 短期足 OHLC, 長期足 OHLC

1. 中期足で「雲」をベースにスイング点を検出
   - スイング検出: 高値・安値（n=3〜5 のフラクタル）+ 雲との位置関係
2. 直近スイングを後ろから 5 点拾い、暫定的に 4-3-2-1-0（= 0 が現在価格）と置く
   - 0 を「4 波終点候補」と仮定
3. 推進波ルール検算
   - 3 波最短ではない
   - 2 波が 1 波始点を割っていない
   - 4 波が 1 波終点を割っていない
4. リトレースメント検算
   - 2 波戻し ∈ [50%, 90%]  (許容を緩めに)
   - 4 波戻し ∈ [25%, 65%]
5. 長期足トレンド一致
   - 長期足 EMA(50) 勾配の符号と一致
6. 短期足エントリートリガー
   - 短期足で雲ブレイク or 直近高安ブレイク
7. 注文発行
   - 損切り: 2 波の終点 - スプレッド余裕
   - 利確: フィボナッチエクスパンション 61.8%（v1）／161.8%（v2）／トレール（v3）
```

## 3. 出口バリエーション（A/B/C/D）

| バージョン | 利確ロジック |
| --- | --- |
| A | エクスパンション 61.8 % 到達で全決済 |
| B | エクスパンション 161.8 % 到達で全決済 |
| C | 61.8 % で半分、161.8 % で残り |
| D | トレーリング（直近スイング or 雲）で全決済 |
| E | C + D ハイブリッド |

## 4. KPI

- 総トレード数
- 勝率
- 平均 RR
- プロフィットファクター
- 最大ドローダウン
- 5 波到達率（4 波完成シグナル × その後 5 波が 3 波を超えた割合）
- フェイラー発生率
- 通貨強弱フィルタ ON/OFF の差分

## 5. 検証対象

- AUDJPY / CHFJPY / EURJPY / GBPJPY / USDJPY（既存ペア群）
- XAUUSD / SILVER（コモディティ）
- NAS100 / SPX500（株価指数）
- 期間: 2015–2025（11 年）
- ウォークフォワード: 学習 3 年 / 評価 1 年のスライディング
