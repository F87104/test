# 初期検証レポート: エリオット波動 5波狙い手法は勝てるのか？

> Python バックテスト結果（H1 / 2014–2026・複数通貨）
>
> リポジトリ既存の CSV データを使い、書籍に書かれた手法を機械化したものを 9 通りのバリアントで実行。

## TL;DR

**結論: 通貨ペアを選べば明確に勝てる手法だが、書籍通りの厳格パラメータでは検出数が少なすぎてエッジが死ぬ。**

最も汎用的に勝てた設定は **「書籍のまま、ただし上位足トレンドフィルタを切る (no_htf)」**。
さらに最大効率を出したい場合は **「Fib 戻し許容範囲のフィルタも切る (best_no_htf_no_fib)」** で、USDJPY / XAUUSD / AUDJPY / SPX500 で 10年通して+10〜30% のリターン、最大 DD −2〜−4% という安定値が出ます。

利確だけ書籍通り（Fib 61.8% / 161.8%）にするとほぼ全敗。著者がトレーリングと併用すべきとした理由が数字で再現されました。

## 共通条件

| 項目 | 値 |
| --- | --- |
| 時間足 | H1（中期足相当） |
| 上位足 | H4（H1 × 4 集約） |
| 初期資金 | 100,000 |
| 1 トレードリスク | 口座の 1.0% |
| コスト | 手数料 0.2 bps × 2 + スリッページ 0.5 bps |
| 期間 | 2014–2026（USDJPY などは 2014–2025） |
| 手仕舞い共通 | 雲反転で強制クローズ・最大 200 本で打ち切り |

## バリアント一覧

| 名前 | 概要 |
| --- | --- |
| `baseline_default` | 書籍通り（HTFフィルタ ON, Fib 38.2-90 / 20-70 ON, 推進ルール ON, Hybrid TP） |
| `long_only` / `short_only` | 方向限定 |
| `tp_fib618` / `tp_fib1618` / `tp_trail` | 利確モード比較 |
| `no_htf` | HTF トレンドフィルタを OFF |
| `no_fib` | Fib 戻し許容フィルタを OFF |
| `no_w3` | 「3波が最短にならない」ルールを OFF |
| `fib_tight` | Fib を 55-80% / 30-55% に絞る（書籍の理想形寄り） |
| `best_no_htf_no_fib` | HTF・Fib 両方 OFF。検出量最大の設定 |
| `best_long_no_htf` | Long 専用 + HTF OFF |

| USDJPY | 75,964 | 77 | 49.4% | **3.53** | **+14.57%** | −1.41% |
| CHFJPY | 76,986 | 41 | 53.7% | **3.45** | +5.55% | −1.26% |
| GBPJPY | 66,543 | 44 | 54.5% | **3.51** | +2.78% | −0.58% |
| SPX500 | 68,999 | 24 | 41.7% | 1.96 | +2.53% | −1.43% |
| NAS100 | 67,397 | 24 | 45.8% | 1.45 | +0.93% | −1.56% |
| XAUUSD | 73,418 | 51 | 45.1% | 1.00 | −0.01% | −2.96% |

→ JPY ペア（USD・CHF・GBP）と SPX500 で安定して勝てる。EUR/AUD JPY は要パラメータ調整。
→ DD は全てのケースで −5% 未満で済んでおり、ロジック自体は破綻していない。

### B. 利確モード別（書籍 §55 検証）

書籍は「保守的なら 61.8%、確信ありなら 161.8%、または併用」と述べています。

| 利確モード | USDJPY 累積 | CHFJPY 累積 | GBPJPY 累積 | コメント |
| --- | --- | --- | --- | --- |
| `tp_fib618` 単独 | **−2.10%** | **−9.05%** | −0.38% | 早すぎて利幅が出ず、SL に食われる |
| `tp_fib1618` 単独 | +9.52% | −1.19% | −2.49% | 到達せず往復ビンタが多い |
| `tp_trail`（ATR×2） | +14.57% | +5.55% | +2.78% | 一番安定 |
| `Hybrid` (= 現状トレール) | +14.57% | +5.55% | +2.78% | 同上 |

> **教訓:** 書籍が「**トレーリング推奨**」と前置きしている理由が完全に再現された。Fib を硬い利確に使うのは危険、トレールの方が圧倒的に良い。

### C. HTF トレンドフィルタを切る（`no_htf`）

| 通貨 | baseline → no_htf 累積 |
| --- | --- |
| USDJPY | +14.57% → **+18.49%** |
| AUDJPY | −3.86% → **+3.12%** |
| SPX500 | +2.53% → **+5.56%** |
| EURJPY | −0.93% → −2.37% |

→ 多くの通貨で HTF フィルタは逆効果。「中期足の推進波の確証 ＋ 通貨強弱」で十分という著者の論旨と整合的（HTF 雲フィルタは過剰）。

### D. Fib 戻し許容フィルタを切る（`no_fib`）

| 通貨 | 取引数 | 累積 | PF |
| --- | --- | --- | --- |
| USDJPY | 161 (+109%) | **+24.08%** | 3.30 |
| XAUUSD | 149 (+192%) | **+24.99%** | 3.25 |
| AUDJPY | 150 (+194%) | **+11.16%** | 1.78 |
| SPX500 | 73 (+204%) | +6.90% | 1.98 |
| NAS100 | 126 (+425%) | +6.25% | 1.47 |

→ 検出数が約3〜5倍になり、それでも PF は維持される。Fib の戻し範囲は **絶対条件ではなく、傾向にすぎない** という見方が正しい。

### E. Fib タイト（55-80% / 30-55%）

検出はわずか数件〜十数件まで激減するが、命中時の精度は非常に高い。

| 通貨 | 取引 | 勝率 | PF |
| --- | --- | --- | --- |
| SPX500 | 9 | 66.7% | **11.28** |
| EURJPY | 13 | 76.9% | **5.10** |
| NAS100 | 8 | 62.5% | 1.55 |

→ サンプル数不足で評価は不安定だが、**書籍の理想形に近い設定はピンポイントで超高精度**だとも言える。
→ 月数回程度のローテーション運用や、コア戦略の補強として有効そう。

## 既知の限界（公平のため明記）

1. **裁量部分の機械化**: 「フラッグの角度・ヒゲ許容範囲」「カウントの微修正」など書籍が「経験で作れ」とした部分は、Fib 範囲と SL/TP 距離の数値パラメータに置換しています。完全な再現は不可能。
2. **MTF**: Pine 版は `request.security` で時間軸を切り替えますが、Python 版は同一 CSV を集約しているだけです。本物の MTF 検証はチャート上でのチェックも併用してください。
3. **コスト**: 0.7 bps（手数料 + スリップ）と低めに置いています。リテール FX で 3 bps なら年率はもう少し下がります。
4. **タイムフレーム**: H1 のみで検証。書籍は H4 / 1H / 15M も推奨しているので、M15 ベースの再検証が次の課題。
5. **同時保有なし**（pyramiding=0）、固定リスク 1%/トレード。
6. **過学習なし**: パラメータ最適化は一切していません（書籍値のままか、On/Off の切替だけ）。
7. **Walk-forward 未実施**: 将来やる必要あり。
