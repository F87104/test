## 経緯

1. **V1 初版**: 書籍記載のロジックを忠実に実装 → 「USDJPY +18%」など好成績
2. **CSV パースバグ発覚**: V1 のスコアは時刻順ソートに由来する偽データだった
3. **V1 訂正版**: 真の結果はほぼ全通貨で PF<1.0、明確なエッジなし

## V2 の追加機能

| 機能 | 内容 |
| --- | --- |
| フラクタル スイング検出 | 雲クロスのバーではなく、その前後の実際の高安値を波の端点に採用 |
| 最小バー数制約 | 各波が `min_bars_per_wave` 本以上ないと無効化（ノイズ除去） |
| ADX フィルタ | ADX > 閾値の時のみエントリー（トレンド相場限定） |
| セッションフィルタ | UTC 7-21 時のみエントリー（London-NY 時間） |
| 通貨強弱フィルタ | 5 通貨ペア相互の 20 本リターンを正規化、base-quote 差で閾値判定 |
| 状態リセット改善 | Pine 仕様に合わせ、シグナル発生時はポジション有無に関わらず常にリセット |

## ウォークフォワード（3yr train / 1yr eval、out-of-sample）

最も重要な検証。in-sample のベストパラメータを次の 1 年でテスト。

| 通貨 | 平均年率リターン | 平均 PF |
| --- | --- | --- |
| USDJPY | **+0.16%** | inf*（数年で勝ち 0 / 数年で 100%） |
| AUDJPY | **+0.21%** | 1.58 |
| CHFJPY | **+0.20%** | inf* |
| SPX500 | **+0.12%** | inf* |

*PF が inf になっているのは年単位のフォールドが小さく、負けトレードが 0 のフォールドが
含まれるため。実質的な期待値は年 0.1〜0.2% 程度。

## 最終結論

1. **書籍記載のロジックを定量化した時点で明確なエッジはほぼ消える** (V1 訂正版で確認)
2. **V2 の改善 (フラクタル + 最小波長 + ADX) で in-sample は PF 1.5–3.0 まで上昇** するが、
3. **ウォークフォワードで年率 +0.1〜+0.2% にまで収束する**（過適合）
4. **特定の年・特定の通貨でしっかり勝つ年がある**（AUDJPY 2018/2023/2025、SPX500 2023 等）
5. しかし**通年で安定したエッジは検出されない**

書籍が「経験で身につける裁量部分が手法の核」と繰り返し強調していたのが、定量的に
完全に裏付けられた結果と言えます。**カウントの修正・フラッグ角度の判定・通貨強弱の
感覚といった人間判断**を機械化したロジックでは現状再現できていません。

## それでも意味があるなら

- AUDJPY を **ADX > 18 + min-bars 4 + Trail 2.0** で運用すると年 0.2% 程度の正の期待値あり
- CHFJPY も同設定で類似挙動
- 月数回しか取引機会がないので、**他の戦略のサテライト** として組み入れ可能
- DD は概ね 1-2% 程度と低いため、リスク的には許容できる
- 単独運用にはエッジが弱すぎる

## 次のステップ案

1. **書籍の通貨強弱章を完全実装**（現状の簡易実装は効果薄）
2. **真の MTF 戦略**（書籍推奨 4H/1H/15M）を実装し、エントリー精度を上げる
3. **裁量部分の補強**: GPT/ML でフラッグ角度・波の質を画像認識
4. **複数戦略のアンサンブル**: 単独で弱いが、他の手法と相関低ければポートフォリオで効く
5. **取引コスト削減**: 0.7 bps 想定だが、実運用ではより重要に
