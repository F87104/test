# HEKIDA（壁打）── 中学生でもわかる版

## ひと言で

**「自分のアイデアを、AIと仲間にきいてもらって、もっと良くしていく場所」**

---

## なんで必要なの？

アイデアって、思いついた時はサイコー！って思うけど、
- 誰に話したらいいか分からない
- 友達に言うとバカにされそう
- ひとりで考えてると、3日で飽きる
- ChatGPTに聞いても、その場かぎりで忘れる

→ **アイデアって、孤独に死んでいく**。これを助けたい。

---

## どんな場所？

### 3つの "顔" がある

1. **AI壁打ち** ── 5人のAIキャラがあなたのアイデアにツッコミ＆提案
2. **仲間レビュー** ── ちゃんと書いてくれる人だけがコメントOK
3. **アイデアの家系図** ── あなたのアイデアから派生したものが系図で見える

---

## 5人のAIキャラ

| キャラ | 役 | 例えると |
| --- | --- | --- |
| **Strategos** | お金とビジネスの話 | クラスで一番現実的なやつ |
| **Critique** | ダメ出し担当 | 「それ無理じゃね？」と言う先輩 |
| **Atelier** | デザイン・気持ちの話 | 美術の先生 |
| **Psyche** | 人の心の動き | 心理の先生 |
| **Operator** | 実際どうやって作るか | 文化祭の実行委員長 |

→ ChatGPTを **5人連れてきた感じ**。役割が決まってるから的確。

---

## 何がスゴいの？（他のサービスと違う点）

### ① いいねボタンが**ない**
- 代わりに「フォーク」「引用」「メンター指名」だけ。
- いいね中毒にならない設計（前のPRで分かった反省を活かす）。

### ② アイデアに**家系図**が付く
- 君のアイデアから誰かが派生アイデアを作ったら、家系図に枝が伸びる。
- 「**おれが祖先かよ！**」って一生自慢できる。

### ③ ちゃんとコメント書く人**しか**コメントできない
- 「いいね！」みたいな1秒で書ける反応は禁止。
- 120字以上の手書きコメントを必須にする。
- → 中身のあるレビューだけが残る。

### ④ 全アイデアは**永久保存**
- 退会してもアイデアは残る。
- 「3年前のあの時のアイデア、今やったら売れるかも」が起きる。

## 例えばこんな使い方

### Aさん（22歳、大学生）
1. 「コーヒー屋×コミュニティ」のメモを書く
2. AI 5人が3ラウンドでツッコみ → 構造化レポートが出る
3. 仲間2人が手書きコメント
4. 別の誰かが「移動コーヒーカー」案を派生 → Aさんは "祖" になる
5. 月1のピッチデーに登壇 → 投資家からオファー
6. 事業化決定！

### B社（新規事業部）
1. 社内10人チームでHEKIDA使う
2. ハッカソンの全アイデアを投入
3. 4ラウンド壁打ちで上位3案を抽出
4. 半年後、1案を子会社化

## ライバルと何が違う？

| ライバル | あっちの強み | こっちの優位 |
| --- | --- | --- |
| ChatGPT | 何でも聞ける | 役割が決まってる・履歴が残る・仲間がいる |
| Notion AI | ドキュメント作り | アイデア専用UI |
| 起業塾 | 対面で熱量 | 24時間・安い・家系図 |
| ツイッター | 拡散できる | 盗まれない・まとまる |

---

## 危ないこと（注意点）

1. **アイデア盗まれる** → タイムスタンプ＋擁護コミュニティで守る
2. **AIの答えが間違う** → 「これ自信ある／ない」を色分け表示
3. **同じような人ばかり集まる** → 招待時に多様性チェック
4. **ChatGPTにマネされる** → 家系図＆コミュニティが堀
