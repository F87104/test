# HEKIDA（壁打）── アイデアを"育てる"プラットフォーム事業設計図

> 仮称：**HEKIDA（壁打）**
> 一文：**「AIと仲間が、あなたのアイデアを最後まで壁打ちしてくれる場所。」**
> 目的：個人〜小規模チームのアイデアを、AIマルチエージェント壁打ち＋人間ピアレビュー＋系譜管理によって、実装・出資に届くレベルまで育てる。
>
> ※ 本書は前PR #4（ALCOVE）と PR #5（承認8軸モデル）を統合し、**「アイデア生成・育成」自体を承認設計の原理で組み立てる**ことを試みた事業設計図。

## 1. なぜ今、これか（市場仮説）

### 1.1 既存の選択肢の限界

| 既存手段 | 何が足りない |
| --- | --- |
| **ChatGPT直叩き** | 単発、文脈消失、専門役割なし、系譜なし、孤独 |
| **Notion + AI** | ドキュメントツールであってアイデア育成ツールではない |
| **Lovable / v0 / Bolt** | "作る"側に偏り、"考える"段階を支えない |
| **起業塾・アクセラレーター** | 高価、選抜制、頻度が低い、対面前提 |
| **社内Slack壁打ち** | 同質的、忖度、批評役不在 |
| **Twitter/X で意見募集** | ノイズ、盗用、まとまらない |

→ **「アイデアを孤独に持っている人が、安全に・継続的に・専門的に壁打ちできる場所」が空いている**。

### 1.2 追い風

- 個人/副業/社内起業の母数の増加。
- LLMコストの低下で、多エージェント運用が現実的に。
- "AI使いこなし格差"が広がり、**伴走型ツール**への需要が顕在化。

## 3. L1：AIエンジン仕様

### 3.1 標準エージェント編成（5体）

| エージェント | 役割 | LLMロール定義の核 |
| --- | --- | --- |
| **Strategos** | 戦略・市場・収益 | 「ロジカル／拡張志向」 |
| **Critique** | 批評・倫理・反証 | 「懐疑主義／失敗モード列挙」 |
| **Atelier** | 体験・言葉・儀式 | 「人間中心／詩的」 |
| **Psyche** | 行動心理・依存 | 「行動経済学／心理学」 |
| **Operator** | 実装・コスト・現実解 | 「PM／実装可能性」 |

ユーザーは **チーム編成をカスタム可能**（弁護士・会計士・デザイナー等の追加エージェントを後から接続）。

### 3.2 壁打ちセッションのフォーマット

1. **入力**：アイデアの種（140〜800字）または既存アイデアのフォーク。
2. **ラウンド1：拡張**（Strategos / Atelier 主導）
3. **ラウンド2：解体**（Critique / Psyche 主導）
4. **ラウンド3：着地**（Operator 主導／実装最小単位の提示）
5. **出力**：構造化レポート（本リポジトリの過去PRと同フォーマット）

各ラウンドは **チャットUI＋構造化サイドパネル** で並行表示。ユーザーはどのラウンドでも介入可能。

### 3.3 組み込みフレームワーク（呼び出し可能なツール群）

- **承認8軸モデル**（前PR #5）
- **3層モデル（L1/L2/L3）**（前PR #4）
- ジョブ理論（JTBD）テンプレ
- 北極星指標選定フロー
- ユニットエコノミクス簡易計算機
- 倫理ガード（ダークパターン検出器）

→ コマンド `/axis8 [idea-id]` などで明示呼び出し。Critiqueは自動的に「倫理ガード」を毎ラウンド実行。

### 3.4 "確信度"の可視化
AIの出力は **(根拠の強さ / 投機性 / 既知の反例)** の3つでタグ付け。
- 緑：根拠あり
- 黄：仮説／要検証
- 赤：投機／断定回避

## 4. L1.5：アイデアのデータ構造（差別化の核）

### 4.1 アイデア=Git的なオブジェクト

```
Idea {
  id, title, body,
  parent_idea_id?,            // フォーク元
  contributors: [user_id],    // ピアレビュアー
  brushes: [Brush],           // 壁打ち履歴（ラウンド単位）
  citations_in: [idea_id],    // 他のアイデアに引用された
  citations_out: [idea_id],   // 他のアイデアを引用している
  derived_ideas: [idea_id],   // 子（フォーク先）
  applied_frameworks: [...],
  certainty_tags: {...},
  visibility: private | invite | public,
  license: ...
}
```

### 4.2 これにより成立する世界

- **フォーク**：他人の公開アイデアを派生させられる（元著者に通知＋系譜記録）。
- **引用**：自分のアイデアの一部に他人の節を埋め込み可（出典自動記録）。
- **被継承数**：自分のアイデアが何回フォークされたかが、プロフィールに集積。
- **系譜ビューア**：あるアイデアの **祖先・子孫ツリー** が可視化。

→ これが **「いいね」を捨てて「被引用・被継承」を単位にする** という前PR #5 の実装。

### 4.3 著作権・ライセンス

- 投稿時に4種類のライセンスから選択（CC-BY 的 / 引用のみ可 / フォーク可 / 完全クローズド）。
- フォーク時はライセンス継承を強制（コンフリクト時は不可）。
- 商用化された場合の **元著者への自動還元（任意設定 1〜10%）**。

## 5. L2：コミュニティ

### 5.1 役割の階層

| 役割 | 条件 | 与えられるもの |
| --- | --- | --- |
| **Sketcher** | 登録時 | アイデア投稿・AI壁打ち |
| **Peer** | 30日活動 | ピアレビュー権／引用 |
| **Mentor** | 高評価レビュー実績 | 限定ルーム／メンター料の受領可 |
| **Curator** | 招待制 | 殿堂入り審査／ピッチデー登壇者選定 |
| **Patron** | 出資者／法人 | 早期閲覧／出資オファー権 |

### 5.2 ピアレビューの設計

- レビューは **120字以上** の手書きを必須化（テンプレ禁止）。
- レビューは公開／非公開選択可。
- 良いレビューには **被引用数** が付く（=メタな承認）。
- 「いいね」ボタンは存在しない。代わりに **「フォーク」「引用」「メンター指名」** のみ。

### 5.3 マッチング機能

- 「あなたのアイデアの **弱点を補完できる Peer**」をAIが提示。
- 「あなたが伸ばせる **他人のアイデア**」を提示。
- 法人スカウト：Patron が "出資/採用したいアイデア" にオファー送信可能。

---

## 6. L3：儀式（忘れがたさの設計）

### 6.1 アイデアの "命名の儀"
投稿初回に AI と対話してアイデアに **正式名** を付ける（後で変更可だが履歴は残る）。

### 6.2 ピッチデー（月次）
- Curators が選んだ Top10 アイデアが、ライブ配信で5分ピッチ。
- 視聴者は **「投資したい」「採用したい」「弟子入りしたい」** の3つの意思表示が可能。
- 殿堂入り条件：3ヶ月連続でTop10入り。

### 6.3 継承式（年次）
- "卒業/事業化" したアイデアの著者が、後継者として若いアイデアの作者に **メンタリング権** を継承。

### 6.4 アーカイブ
- 全アイデアは退会後も **「永久アーカイブ」** に残る（本人の選択でクローズ可）。
- "死蔵されたアイデア" を **発掘者（Excavator）が引き取って再生** できる制度。

## 7. ビジネスモデル

### 7.1 収益ライン

| プラン | 想定単価 | 内容 |
| --- | --- | --- |
| **Free** | ¥0 | AI壁打ち月3回、公開アイデアのみ |

| **Patron**（法人） | ¥98,000/月〜 | 早期閲覧／オファー権／カスタムエージェント |
| **マーケットプレイス手数料** | 取引額の8〜15% | アイデア売買／メンター料／出資マッチ |
| **イベント** | 都度 | ピッチデー観覧／継承式登壇 |

### 7.2 ユニットエコノミクス仮置き

- AIコスト：1壁打ちセッション ¥40〜¥120（モデル選定で変動）
- Pro粗利率：65〜75%
- 想定ARPU：¥3,500（Free混在）
- LTV：¥45,000（年間継続）
- CAC：¥1,500〜¥3,500（招待制＋一部広告）

### 7.3 二次収益（重要）

- **ナレッジパッケージ販売**：人気フレームワーク（8軸モデル等）を法人研修用にパッケージ化。
- **データ匿名分析レポート**：業界別アイデア動向（個人特定不可形態で）。
- **新規事業コンサル**：法人向け伴走支援（メンター紹介＋AIチームレンタル）。

## 10. ユーザー・ジャーニー（具体例）

### 10.1 個人クリエイター（β層）
1. 「焙煎所×コミュニティ」のメモを書く
2. AI壁打ち3ラウンド → 構造化レポート生成
3. Peerが2名レビュー、Strategosが指摘した収益モデルが補完される
4. 別ユーザーがフォーク → 「移動焙煎車」案が派生、被継承数+1
5. ピッチデー登壇 → Patronから出資オファー
6. 事業化決定。元アイデアは殿堂入り。

### 10.2 法人新規事業担当
1. Studioプランで社内10名チーム編成
2. 社内ハッカソンの全アイデアを HEKIDA に投入
3. 4ラウンド壁打ちで上位3案を抽出
4. Mentor（外部）を月額で接続
5. 半年後に1案を子会社化

## 16. 四者の最終所見

**Strategos**:
> ChatGPT直叩きとの差別化は **(1)役割固定の専門エージェント (2)アイデアの系譜管理 (3)コミュニティ層** の3点同時。
> 単体機能では真似されるが、3点同時は堀になる。**Phase 1 のフォーク行動率がKPIの心臓**。

**Critique**:
> 「アイデアプラットフォーム」は墓場である。Quora、Producthunt、各種国内コミュニティの大半は失敗した。
> 生存するためには **(a)所有権の堅牢な保護 (b)いいね非搭載の覚悟 (c)有料転換の早期成立** が必須。
> 特に **(b)** は短期成長を犠牲にする決断。経営陣が覚悟できるかが分水嶺。

**Atelier**:
> "アイデアを持っている人" は本質的に孤独。彼/彼女が欲しているのは評価よりも **「ちゃんと聞いてもらえた」感覚**。
> AI壁打ちはそれを24h提供できる唯一の手段。**ピアレビューは手書き120字**を絶対に妥協するな。
> "あなたのアイデアに、5人の専門家を。" これがブランド軸。

**Psyche**:
> アイデアを出すこと自体が承認欲求の発露。だが「投稿数」を競わせると低質化する。
> **「壁打ち回数」「被引用数」「被継承数」** の3つだけを表示し、他の指標は隠せ。
> 通知は1日2回上限、夜間ミュート必須。**Slow Idea Platform** こそ独自性。

**Operator（新規参加）**:
> MVPは **AI壁打ち＋系譜＋招待制** の3点で十分検証可能。3〜4ヶ月で原型は組める。
> インフラ：LLMはモデル切替可能な抽象層／ベクタDB（Idea埋め込み用）／系譜は素直にPostgresで足る。
> 月額¥2,800のPro転換15%が損益分岐点ライン。
